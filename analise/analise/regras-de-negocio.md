# Regras de Negócio

Documento destinado à especificação das regras de negócio do Sistema de Gestão de Eventos da Eventus.
RN01 — Limite de vagas

Uma atividade não pode possuir mais inscrições confirmadas do que sua capacidade máxima.

RN02 — Lista de espera

Quando uma atividade atingir sua capacidade máxima, novas solicitações poderão ser direcionadas para uma lista de espera, caso essa funcionalidade esteja habilitada para a atividade.

RN03 — Cancelamento

O cancelamento somente poderá ocorrer quando permitido pelas regras do evento.

RN04 — Reembolso

O direito ao reembolso depende das regras definidas para o evento/inscrição.

RN05 — Pagamento

Para eventos pagos, determinadas inscrições somente poderão ser confirmadas após a confirmação do pagamento.

RN06 — Conflito de horários

O sistema deverá verificar conflitos entre atividades selecionadas pelo participante.

RN07 — Certificação

A emissão do certificado deverá estar condicionada às regras de participação/presença definidas para o evento.
