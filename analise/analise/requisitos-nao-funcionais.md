# Requisitos Não Funcionais

Documento destinado à especificação dos requisitos não funcionais do Sistema de Gestão de Eventos da Eventus.

RNF01 — Desempenho
O sistema deve apresentar as páginas de consulta de eventos dentro de um tempo máximo definido.

RNF02 — Segurança
O sistema deve restringir o acesso às informações de participantes de acordo com o perfil do usuário.

RNF03 — Privacidade
O sistema deve proteger os dados pessoais dos participantes e atender à legislação aplicável.

RNF04 — Disponibilidade
O sistema deverá apresentar um nível de disponibilidade previamente definido pela empresa.

RNF05 — Acessibilidade
A interface deverá atender aos requisitos de acessibilidade definidos para o projeto.
