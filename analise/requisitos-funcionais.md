# Requisitos Funcionais

Documento destinado à especificação dos requisitos funcionais do Sistema de Gestão de Eventos da Eventus.
| ID   | Requisito                                                                            |
| ---- | ------------------------------------------------------------------------------------ |
| RF01 | O sistema deve permitir consultar os eventos disponíveis.                            |
| RF02 | O sistema deve permitir visualizar informações detalhadas de um evento.              |
| RF03 | O sistema deve permitir realizar inscrições.                                         |
| RF04 | O sistema deve controlar automaticamente a quantidade de vagas.                      |
| RF05 | O sistema deve permitir inscrições em múltiplas atividades.                          |
| RF06 | O sistema deve identificar conflitos de horário.                                     |
| RF07 | O sistema deve permitir cancelamento de inscrições quando permitido.                 |
| RF08 | O sistema deve controlar a lista de espera.                                          |
| RF09 | O sistema deve registrar pagamentos.                                                 |
| RF10 | O sistema deve permitir confirmação de pagamentos.                                   |
| RF11 | O sistema deve controlar reembolsos.                                                 |
| RF12 | O sistema deve permitir emissão de certificados.                                     |
| RF13 | O sistema deve permitir aos palestrantes consultar participantes de suas atividades. |
| RF14 | O sistema deve permitir aos organizadores acompanhar inscrições em tempo real.       |
| RF15 | O sistema deve enviar comprovantes e notificações aos participantes.                 |
